# EDA cũ 2010–2026

01_gold_eda_v2, 02_oil_eda_v2, 03_dollar_index_eda_v2, 04_sp500_eda_v2 phân tích bốn snapshot trong `data/eda_2010_2026`. Phần Data Profiling mô tả chất lượng và phân phối dữ liệu gốc; Feature-oriented EDA mô tả biến động, xu hướng và các đặc trưng riêng từng nguồn.

Dữ liệu EDA giữ phạm vi 2010–2026, tách khỏi bộ modeling 2005–2026. Output được tính từ chính các snapshot EDA này trong môi trường local. Không có DFF.
