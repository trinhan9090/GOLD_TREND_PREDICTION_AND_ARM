# ARM-H5 — Train và Validation

arm_h5.ipynb tự đọc data/modeling/horizons/h5, purge, fit encoding trên Train, chạy Apriori và hiển thị 27 cấu hình trên Val. Ghi dữ liệu/encoding tại data/arm/ARM-H5 và bảng results/arm/1_train/H5_rules.csv. Không tính Test tại đây. Sau khi đủ bốn horizon, chạy ../ARM-FINAL/arm_test.ipynb rồi arm_rule_discovery.ipynb.
